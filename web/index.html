Rules that passed

    Holding it

      Your model

      Point Coeus at a model you already have, or export a pack and import that into the model. A local model never leaves this computer.

      Second model

      Used only when the box on Plan is checked. It can refuse the trade. It cannot skip Send.

      Hyperliquid

      A separate API wallet does the trading. Your main wallet key is not a field here. That API wallet can place and cancel orders. It cannot withdraw. Revoke it on Hyperliquid, under API, when you want it to stop.

      The orders switch is in the top bar. Save writes the model and the account together. Keys live in ~/.coeus on this computer.

      Stop

      Pause sends and cancel open orders.

      This cancels working orders on the network in the top bar. It does not close a position, and it does not withdraw. Hidden stops will not fire until you arm Coeus again.

      Mainnet

      This order is real.

      Type MAINNET to send it. Testnet is the other choice in the top bar.

      Not financial advice. Leveraged trades can lose money. A hidden stop fires only while this window is open.
